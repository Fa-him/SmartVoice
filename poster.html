SmartVoice
Personalized PC Assistant for Offline, Privacy-First Task Automation via Voice Commands
Batch: 16th  |  Session: 2022–23
Course: CSE 4100
Date: 22 April 2026
💡
Introduction
  • Offline, privacy-first desktop voice assistant for Windows
  • All processing (STT, NLU, Executor, TTS) runs locally — zero cloud dependency
  • Automates system control, file management & productivity tools
  • Confirmation prompts prevent accidental critical actions
  • Tamper-resistant audit log records every command
  • Modular design enables future cross-platform expansion
🎯
Objectives
  • Local STT pipeline with WER ≤ 10%, latency ≤ 300 ms
  • Secure Command Executor with allow-list & confirmation guards
  • All audio & data stays on-device — no network transfer
  • Encrypted SQLite DB + tamper-resistant command log
  • End-to-end validation: WER, latency, SUS ≥ 80
  • Full technical docs, user manual & demo prototype

Scope & Limitations
  • Initial target: Windows 10+; architecture allows future expansion
  • No cloud, biometric auth or emotion recognition in scope
  • Commands restricted to allow-listed actions
  • Offline STT may struggle with heavy accents / noisy rooms
